# XWeave

XWeave is the alternate spelling of **[crossweave](https://github.com/uhuntu/crossweave)** — a tiny, dependency-free wrapper that weaves the Claude Code, Codex, Kimi, step, CodeBuddy and ZCode CLIs behind one set of flags, plus cross-tool session discovery, resume, and handoff.

This package holds the name: installing it installs `crossweave` itself. The commands are `cw` and `cx`.

```bash
pip install xweave        # same as: pip install crossweave
```
